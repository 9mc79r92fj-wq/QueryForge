# V2 Bad Case 分析方法

## 状态

本轮未采集新样本。本文定义方法，供下一阶段对照实验使用。

## 分类维度

1. **检索层**：相关文档未被召回（BM25 词项不匹配 / Dense 语义漂移）、召回但排名靠后
2. **路由层**：策略选错（关键词查询走了语义通道、长问句走了单通道）
3. **精排层**：精排把正确结果排到后面；或本应精排却跳过
4. **证据层**：召回正确但切分丢上下文
5. **生成层**：模型忽略证据、引用错误、超范围推断
6. **拒答层**：证据充分却拒答 / 证据不足却作答
7. **系统层**：超时、限流、降级、缓存污染

## 采集流程

```
固定测试集 → 记录每次路由决策与分数 → 标注期望结果
→ 对失败样本按上述维度打标 → 汇总各类型占比与延迟分布
→ 选 3–5 个代表样本写具体分析（输入、判定、期望、实际、修复建议）
```

## 报告要求

- 报告分母（样本总数）与失败率，不只挑失败案例
- 不同策略分开统计，避免平均值掩盖差异
- 每条结论附可复现的查询 ID 与配置版本
